# ATM Bank Management System
A console-based ATM Bank Management system implemented in (C++)

# Features

### 1. Authentication & Security
- **User login system**: Secure authentication with username and password verification.
- **Role-Based access control (RBAC)**: Fine-grained permission system implemented using **Bitwise Operations** to restrict access per menu (Show, Add, Delete, Update, Transactions, Manage Users, Full Access).

### 2.Banking Transactions:
- **Quick Withdraw**: Pre-defined amount selection.
- **Normal Withdraw**: Custom amount withdraws (multiples of 5).
- **Deposit**: Account balance credits.
- **Check Balance**: Instant account balance checking.
- **Data Persistence**: Automatic file storage (`Clients.txt`).
